This folder is the record of the final choices. The images themselves are not kept here, on purpose (see [Where the files live](#where-the-files-live)).

## Where the files live

| What | Where |
|---|---|
| Masters (2048px PNG, finished) | Design repo, `~/Sites/suits-sandals-design/insights-thumbnails/deliver/finals-2048/`, named after the frame (`ss-insights-NN-name.png`) |
| Renders, decisions, approvals | The same design repo (`insights-thumbnails/`): `README.md`, `DECISIONS.md`, the FLORA working files in `flora/` |
| Published copies | The CMS media library, Asset Library "Suits & Sandals Insights", one item per frame (ids in the table), stored in R2 |

Why not in this repo: the full set is about 136 MB of PNGs. Committed here, every clone, workspace and Vercel build would carry them for good, and anything under `public/` is served as a public URL. The design repo already holds the masters with their history, and the CMS holds the copies the site serves.

## Changing a frame

1. Re-render or re-finish the frame in the design repo, never in this repo. Update the placement JSON there.
2. Upload the finished file to the "Suits & Sandals Insights" library with `pnpm cms:upload <file> --library 10 --alt "<what the picture shows>"` (steps in the article-authoring skill). Send a JPEG of the 2048px master: the site host refuses uploads over about 4.5 MB, and the CMS re-encodes to WebP either way.
3. Set the new media id as the post's hero image and SEO image, as a draft. Leave the share-card image (`meta.og.image`) alone unless it should change too.
4. Publish when the change is approved, then delete the media item the post no longer uses.
5. Copy the updated placement JSON here and update the table.

## Notes

- Frames that were re-finished after a first upload carry a `-v2` suffix in the CMS (for example `ss-insights-17-chalk-diagram-v2.webp`). The `-v2` items are the current finish.
- The earlier finish (media 243 to 249 and 257 to 268, plus 270) was deleted on 2026-10-16. Its one survivor is `ss-insights-20-ferry-rail.webp` (media 269), the only copy of that frame, kept as a spare; no post uses it.
- The square frames are also the SEO image, so social cards that want a landscape image will crop them. A landscape crop in `meta.og.image` fixes that per post.
- Alt text for every frame is on its media item in the CMS, written from the picture in house style.
